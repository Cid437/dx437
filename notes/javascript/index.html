JavaScript Fundamentals

A quick reference covering the basics tested in the matching quiz.

Variables

let declares a block-scoped variable that can be reassigned. const declares a block-scoped binding that cannot be reassigned (though objects/arrays it points to can still be mutated). var is function-scoped and mostly avoided in modern code.

let count = 1;
const name = "Ada";
count = 2;      // ok
name = "Grace"; // ❌ TypeError: Assignment to constant variable.

Equality: == vs ===

=== compares value and type with no conversion. == compares after converting types, which often causes surprising results.

5 === '5'   // false
5 == '5'    // true

Types

undefined means a variable was declared but never assigned a value. null means "intentionally empty." typeof null famously returns "object" — a long-standing JavaScript quirk.

Functions

Declared with function, and values are sent back with return. Arrow functions (() => {}) are a shorter alternative commonly used for callbacks.

Arrays

  • push() / pop() — add / remove from the end
  • shift() / unshift() — remove / add at the start
  • map() — transform every item into a new array
  • filter() — keep only items that pass a test
  • find() — return the first item that matches
  • reduce() — combine all items into a single value
  • slice() — copy a portion without changing the original
  • concat() — combine two arrays into a new one
[1, 2, 3].map(x => x * 2);        // [2, 4, 6]
[1, 2, 3].filter(x => x > 1);     // [2, 3]
[1, 2, 3].reduce((a, b) => a + b) // 6

JSON

JSON.parse() turns a JSON string into a JavaScript object. JSON.stringify() does the reverse.

Async JavaScript

An async function always returns a Promise. Inside it, await pauses execution until that Promise resolves, letting asynchronous code read top-to-bottom like synchronous code.

async function load() {
  const data = await fetchData();
  console.log(data);
}
Forgetting await is a common bug — you'll be left holding a Promise object instead of the actual data.

Error handling

Wrap code that might fail — especially awaited calls — in try/catch so errors don't crash the app.

try {
  const data = await getData();
} catch (err) {
  console.error(err);
}

Timers

setTimeout() runs code once after a delay. setInterval() runs code repeatedly on a fixed delay.
