Node.js

A quick reference covering the basics tested in the matching quiz.

Core modules

  • fs — read and write files (fs.readFile(), fs.writeFile(), fs.unlink() to delete)
  • http — create web servers
  • path — build and inspect file paths (path.join(), path.dirname(), path.extname())
  • os — information about the operating system, e.g. os.platform()
  • crypto — cryptographic functionality, such as generating secure random tokens
const fs = require('fs');
fs.readFile('notes.txt', 'utf8', (err, data) => {
  if (err) return console.error(err);
  console.log(data);
});
fs.readFile() is asynchronous — the data isn't available until the callback runs, not on the next line.

CommonJS modules

Use require() to load a module and module.exports to expose values from one.

// math.js
function add(a, b) { return a + b; }
module.exports = { add };

// app.js
const { add } = require('./math');

process & environment variables

process is a global object with info about the running program. Environment variables (e.g. secrets, ports) are read through process.env, never hardcoded.

const port = process.env.PORT || 3000;

npm

  • npm install <package> — install a dependency
  • npm install <package> --save-dev — install a development-only dependency
  • package.json — lists a project's dependencies and scripts
  • node_modules — where installed packages live
  • npm run <script> — runs a script defined in package.json

HTTP & REST basics

  • GET — retrieve data
  • POST — create a new resource
  • PUT / PATCH — update a resource
  • DELETE — remove a resource

Common status codes: 200 success, 404 not found, 500 server error.

Express essentials

If req.body is undefined in a POST handler, the JSON body-parsing middleware is usually missing:

app.use(express.json());

Serve a folder of static files with:

app.use(express.static(__dirname + '/public'));

Async patterns & the event loop

Node handles many concurrent requests without blocking thanks to its event loop and non-blocking I/O — long-running work (like file or network access) doesn't stop the rest of the program from running.

app.get('/', async (req, res) => {
  try {
    const data = await getData();
    res.json(data);
  } catch (err) {
    res.status(500).send('Something went wrong');
  }
});
